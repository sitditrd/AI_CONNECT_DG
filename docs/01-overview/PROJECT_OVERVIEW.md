# Connect DG — 프로젝트 개요

**AI 기반 위험물 물류 통합 플랫폼** · TaeSLA 4기 최종 과제 (2026)

## 배경 (발표자료 1부 · 현황)

- 글로벌 위험물 물류는 연 6~8% 성장(협의 CAGR 6.0%, 광의 8.1%), APAC이 최고 성장 권역.
- 국내 위험물 제조소등 108,829개소(2024.12.31) 중 화주가 빌릴 수 있는 **영업용 허가 창고(옥내저장소)는 8,702개소뿐**.
- 제4류 인화성액체가 유별 허가의 96.8% — 사실상 석유류 물류. 이차전지·특수화학 수요는 급증하나 공급 희소.
- 화학사고 연 200~282건, 5건 중 1건은 운송 중 발생(탱크로리 54%).
- 위험물 운송사 수를 집계한 공식 통계 부재 — 시장이 파편화·불투명.

## 문제 (2부 · 구조적 4대 문제)

1. **매칭 부재** — 적재 가능 창고·차량 탐색 채널 없음, 전화·인맥 의존
2. **공급 희소** — 허가 창고 만성 부족, 신규 허가 진입장벽
3. **안전·규제 이중 부담** — 소방청(위험물안전관리법) · 환경부(화학물질관리법) 이원 규제
4. **정보 단절** — 수기·엑셀 기반, 실시간 가시성 부재

## 해결책 (3부 · 본 웹이 구현한 범위)

**화주 · 위험물 창고 · 운송사 3면 네트워크** 위에서:

| STEP | 기능 | 구현 화면 |
|---|---|---|
| 01 | MSDS 분석 (LLM-OCR → 표준 위험물 프로파일) | msds.html |
| 02 | 적법성 사전검토 (4단계 방어 절차) | compliance.html |
| 03 | 창고·차량 매칭 (가중치 6종 · 안전경로) | matching.html · route.html |
| 04 | 계약·배차·관리 (실행 6단계 · 감사 로그) | dispatch.html |

9단계 흐름: 보관 요청 → MSDS 등록 → 정보 추출 → 법규 검토 → 창고 매칭 → 경로 검토 → 견적·계약 → 배차 → 입고 관리(TIMS 연계)

## 원칙

- AI는 판단을 대신하지 않는다 — **전문가가 검토할 근거를 구조화**한다.
- 대외 표현은 "100% 적법·완전 면책"이 아닌 **"법률 적합성 사전검토 + 전문가 검토 지원"**.
- 종합 추천점수는 우선순위 지표이며 적법성을 확률로 보증하지 않는다.
- 모든 결과에 적용 근거 · 원문 페이지 · 출처 · 조회 시각 · 승인자 · 변경 이력을 함께 저장(감사 추적).
