## 비기능 요구사항

- **NFR-01 오프라인 우선** — Supabase 미연결 시 내장 시드로 전 기능 동작
- **NFR-02 키 보안** — 클라이언트에는 publishable key만, RLS로 보호, service key 금지
- **NFR-03 접근성** — 판정·상태는 색+텍스트 병기, skip-link, aria-label, prefers-reduced-motion 대응
- **NFR-04 감사 추적** — 모든 확정 행위는 시각·행위자·내용이 로그로 남음
- **NFR-05 단계별 정보 공개** — 탐색 단계 창고명·주소 가림, 계약 확정 후 공개 (23장 잔류가치 장치)
