# 시스템 구현 범위 및 신뢰성 검증

> 작성 2026-09-18 · 보강 2026-09-21(문서 판독 · 보관 조건 · 시연 데이터 원본 대조) · 화면 `verify.html`(구현·검증) · 규칙 모듈 `js/verify-rules.js`
> 심사 질의(① 배차·경로 ② LLM·OCR 문서 판독 ③ 법규 검증·창고 매칭)에 대해
> **현재 구현된 것과 추가 개발·검증이 필요한 것을 구분**해 정리한다.
> 화면의 전환 기준표와 법령 대조표는 코드(`DGVerify`)에서 직접 그리므로 이 문서와 화면이 어긋나지 않는다.

**전제** — 시연 화면은 실제로 동작하는 코드이고, 데이터(창고 8곳 · 차량 5대 · 경로 후보 · 실제 MSDS 3종)는 검증용 샘플이다.

상태 표기: **구현**(시연에서 실제 동작) · **부분**(로직은 동작, 데이터 또는 연동이 샘플) · **미구현**(추가 개발).

## ② LLM · OCR 기반 문서 판독

### 구현 현황

| 기능 | 상태 | 내용 |
|---|---|---|
| 문서 AI 분석 | 부분 | PDF · 스캔 · 이미지를 JSON 스키마로 구조화하는 코드 구현. **분석 서버(`msds-extract`)는 미배포** — 시연은 실제 MSDS 3종의 사전 검증 결과 재생(화면에 '데모 재생' 명시) |
| 비정형 문서(B/L) | 부분 | 분석 엔진에 문서 유형 파라미터(`doc_type`: `msds` · `bl`)와 **B/L 스키마** 구현 — 당사자 · 선박 · 항로 · 컨테이너 · 위험물 신고 행(UN · PSN · Class · PG · MP). 실제 B/L 샘플 · 정답지 검증과 화면 연결은 추가 개발 |
| 양식 · 언어 · 스캔 품질 | 구현 | 모든 문서 유형에서 **문서 특성(`docMeta`: 언어 · 형식 · 판독 품질 · 양식 · 발행처)**을 함께 판독. 저품질 스캔 · 사진 촬영본 · 정답지로 검증되지 않은 언어(현재 검증 언어는 영어)는 '확인 필요'로 전환(전환 기준 'docQuality') |
| 정확도 채점 도구 | 구현 | `test/msds-eval.js` + `test/eval/gold/*.json` — 실제 MSDS 3종 원본의 원문 표기 · 쪽수 · 원문 오기 정답지. 분석 엔진 결과도 `--pred` 로 같은 기준 채점 |
| 원문 위치 · 신뢰도 · 인식 적합도 | 구현 | 필드별 섹션 · 페이지 · 신뢰도, 적합도 4지표(완전성 35 · 신뢰도 30 · 추적성 20 · 정합성 15). **원문 영역(좌표) 하이라이트는 미구현** |
| 오류 검출 | 구현 | 필수 필드 누락 · 신뢰도 80% 미만 · 적합도 85점 미만 · **CAS 체크디짓** · **농도와 분류 상충**을 '확인 필요'로 전환 |
| 원문 대조 수정 | 구현 | 추출표 '수정' — 전후 값 · 사유 · 수정자 · 일시를 이력으로 남기고, 핵심 필드는 표준 프로파일에 반영(적합도 재산정) |

### 실측 결과

| 항목 | 결과 | 판단 |
|---|---|---|
| 규칙 기반 파서(무료) | 39칸 중 12칸 적중(약 30%) — 섹션 헤더 · 2단 레이아웃 · 라벨 표기가 문서마다 다름 | 기각 |
| 무료 OCR · 문서 AI 5종 | 문서당 2페이지 제한(Section 14는 6~10쪽), OCR 노이즈, 정확도 근거 없음 | 기각 |
| 시연 데이터 원본 대조 | 원본 PDF로 정답지를 만들어 채점 — 정정 전 **필드 19/30 · 쪽수 7/25 · 총 쪽수 0/3** → 정정 후 **30/30 · 25/25 · 3/3** (성분 · 함유량 · 터널코드 · 특별규정 등 원문에 없는 값 제거) | 정정 완료 |
| CAS 체크디짓 | 원문 오타 2건 검출 — 1370-96-6 → 1307-96-6 (3480 원본 p.2 Cobalt oxide 로 교차 확인), 12190-79-7 → 12190-79-3. 교정 이력으로 기록 | 적용 |
| 원문 오기 · 표기 | UN 30777(3077 p.10 3곳) · HAZRDOUS 철자 · 'Packing grade: 2' · 아래첨자로 CAS 사이 공백 — 원문 대조 수정 이력으로 기록 | 적용 |
| 농도 · 분류 교차검증 | UN3098 기재 문서의 H₂O₂ 2~6% — UN 운송 규제 하한(8%) 미만과 상충 검출 | 적용 |
| LLM 분석 정확도 | 미측정 — 채점 도구는 준비 완료, 서버 배포와 샘플셋 구축 후 같은 기준으로 측정 | 검증 필요 |

시연 3종의 적합도 점수는 사전 검증 프로파일과의 대조값이며 정확도 실측치가 아니다.

### 정확도 검증 계획

- **샘플** — 30건 이상. 제조사(국내 · 해외) · 언어(국 · 영 · 중 · 일) · 형식(텍스트 PDF · 스캔 · 사진) · 스캔 품질(상 · 중 · 하)로 층화
- **정답지** — 위험물 담당자 2인 독립 판독 후 불일치 합의
- **지표** — CAS · UN · Class · PG · 성분 · 함유량별 정확도, 누락률, 오인식률, 원문 위치 일치율, 처리 시간
- **합격 기준(안)** — UN · Class · PG 오인식이 '확인 필요' 없이 통과되는 건 0건. 나머지 필드는 측정 후 기준 설정
- **채점** — `node test/msds-eval.js --pred <분석결과 폴더>` 로 필드 · 쪽수 · 총 쪽수 정확도 산출(정답지는 `test/eval/gold/`)
- **다른 문서(B/L 등)** — B/L 스키마 구현 완료. 실제 샘플과 정답지로 검증 후 화면 연결

### 누락 · 오인식 처리 절차

1. 자동 검사 — 누락 · 저신뢰 · 저적합도 · CAS 체크디짓 · 농도와 분류 상충 · 문서 품질과 언어 (구현)
2. '확인 필요' 표시 — 필드와 원문 섹션 · 페이지 제시 (구현)
3. 담당자 원문 대조 · 수정 — 전후 값 · 사유 · 수정자 이력 저장 (구현), 원문 영역 하이라이트 (미구현)
4. 전문가 승인 후 확정 (구현)

원칙 — 읽지 못한 값은 빈칸으로 두지 않고 '확인 필요'로 넘긴다. 틀린 값이 '확정'으로 넘어가지 않게 하는 것이 목표다.

## ③ 법규 검증 및 창고 매칭

### 읽는 기능과 판단하는 기능의 분리

- **읽기(문서 AI)** — UN No. · Class · PG · CAS · 농도를 원문 위치와 함께 추출. 판단하지 않는다.
- **판단(규칙 엔진)** — 국내 유별 판정 → 요구 허가 산출 → 창고 인허가 · CAS 허가 품목 대조 → 적합 · 조건부 · 보류 · 불가와 사유.
- **확정(담당자)** — 승인 전에는 최종 판정을 확정하지 않는다. 전환 사유가 남아 있으면 승인 후에도 조건부.

### 현재 판단 규칙

- 주 등급 허가 없음 → 보관 불가 / 국내 유별 확정 품목인데 해당 유별 허가 없음 → 보관 불가
- 부차위험 허가 미보유 → 조건부 / 정기검사 기간 경과 → 보관 불가(만료 임박 감점)
- 공간 부족 → 조건부 / 가동률 100% → 보류 / 혼재 금지 매트릭스(시행규칙 별표19)
- **CAS 단위 허가 품목 대조(신규)** — 화관법 관리 대상 성분이 있으면 창고 허가 품목(CAS)과 대조. 목록이 있는데 없는 성분이 있으면 조건부, 목록이 없으면 '인허가 원본 확인'으로 표시(판정 영향 없음).
  예: 3077(코발트 화합물)에서 W-08은 Class 9 허가와 점수 98로 최고점이지만 등록 품목에 코발트 CAS가 없어 조건부.
- **물품(Article)** — 셀 · 배터리처럼 물품인 경우 화관법 허가 품목(CAS) 대조 비대상으로 표시(3480)
- **보관 조건(온도) 대조(신규)** — MSDS 보관 온도 표기(냉장 · 정온 · 실온 · 상온)에서 온도구역 요구를 도출해 창고 온도구역과 대조. 기재가 없으면 요구 없음으로 표시
- 추천점수(가중치 6항목)는 순위용 — 판정과 분리

### 담당자 확인 전환 기준 (13개)

| 조건 | 예시 | 현재 |
|---|---|---|
| 전문가 승인 전 | 모든 건 | 구현 |
| 필수 필드 누락 | UN No. · Hazard Class 미기재 | 구현 |
| 추출 신뢰도 80% 미만 | 흐린 스캔의 성분 · 함유량 | 구현 |
| 인식 적합도 85점 미만 · 실문서 | 정답지 없는 업로드 문서 | 구현 |
| CAS 체크디짓 불일치 | 12190-79-7 (정답 12190-79-3) | 구현 |
| 농도 · 분류 상충 | H₂O₂ 2~6%인데 Class 5.1 기재 | 구현 |
| 국내 유별 판정 유보 | 농도 범위가 유별 기준에 걸친 물질 | 구현 |
| 문서 표기 충돌(검토 메모) | 문서의 국내 법령 표기와 UN 분류 불일치 | 구현 |
| 지정수량 환산 불가 | 국내 위험물인데 품명 · 환산 정보 없음 | 구현 |
| 부차위험 허가 미보유 창고 | Class 5.1(8) → Class 8 허가 없음 | 구현 |
| 창고 허가 품목(CAS) 미등재 | Class 9 허가는 있으나 코발트 화합물 미등재 | 구현 |
| 근거 법령 개정 · 규칙 재검토 | 규칙 검토일 이후 시행되는 개정 | 부분 |
| 문서 품질 · 언어 미검증 | 저품질 스캔 · 사진 촬영본 · 정답지 미확보 언어 | 구현 |

**전환 사유가 하나라도 있으면 전문가 승인 후에도 판정은 '적합'이 아닌 '조건부 검토'로 남는다.** 사유는 적법성 검토 화면에 목록으로 표시되고, 판정 기록 · 적합성 리포트에 함께 저장된다.
